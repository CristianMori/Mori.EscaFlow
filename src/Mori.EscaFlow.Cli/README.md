# Mori.EscaFlow.Cli

The `escaflow` command line tool: `parse` (summary, diagnostics, model JSON), `ir build` / `ir validate` /
`ir print` (middle file), and `generate csharp` (a complete C# solution). Run with
`dotnet run --project src/Mori.EscaFlow.Cli -- <command>`; the usage text lists every option.
